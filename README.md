## 🚀 Features

### 👤 User
- Browse events
- Search & filter events
- Book tickets
- Online payment (Razorpay)
- View bookings

### 🎤 Organizer
- Create events
- Manage events
- View bookings & attendees

### 👑 Admin
- Dashboard analytics
- Manage users
- View all transactions
- Platform overview

---

## 🛠 Tech Stack

- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB
- Payment: Razorpay
